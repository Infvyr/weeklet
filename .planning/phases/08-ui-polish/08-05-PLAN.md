<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Visual verification of all 5 UX requirements</name>
  <what-built>
    UX-01: Centered empty state on expenses screen when list is empty
    UX-02: PDF export icon hidden when expenses or income list is empty
    UX-03: 4-tab bottom nav (no Categories tab); categories icon in expenses AppBar navigates to CategoriesScreen
    UX-04: Annual evolution amounts show compact notation (e.g. "1.2K MDL") in MonthlyBarRow and MonthlyItem balance header
    UX-05: Scrollbar thumb visible on scroll in main screens; absent inside modal bottom sheets
  </what-built>
  <how-to-verify>
Launch the app on a device or emulator: fvm flutter run

Verify each requirement:

UX-01 — Expenses empty state:
  1. Delete all expenses (or use a fresh install)
  2. Open Expenses tab
  3. EXPECTED: "No expenses yet" / "Tap + to add your first expense" centered vertically on screen
  4. FAIL if: text is at the top of the screen (not centered)

UX-02 — PDF export hidden when empty:
  1. With expenses list empty: confirm PDF export icon is ABSENT from AppBar (only the Categories icon appears)
  2. Add one expense: confirm PDF export icon APPEARS in AppBar
  3. Open Income tab with empty list: confirm PDF export icon is ABSENT
  4. Add one income: confirm PDF export icon APPEARS

UX-03 — Categories navigation:
  1. Count bottom nav tabs — EXPECTED: exactly 4 (Home, Income, Stats, Settings). No Categories tab.
  2. Open Expenses tab, tap the category icon (grid icon) in the AppBar
  3. EXPECTED: CategoriesScreen opens with a back button (pushed route, not tab switch)
  4. Tap back — returns to Expenses

UX-04 — Compact amounts in stats:
  1. Navigate to Stats screen
  2. Find a month with income or expenses >= 1000
  3. EXPECTED: MonthlyBarRow amount text shows "1.2K MDL" format (not "1,200.00 MDL")
  4. EXPECTED: MonthlyItem balance header shows compact format (e.g. "2.1K MDL" not "Balance: +2 081 MDL")
  5. For months with amounts < 1000: normal format (e.g. "999.99 MDL")

UX-05 — Scrollbar on main screens, absent in sheets:
  1. On Expenses tab with multiple expenses: scroll the list — EXPECTED: scrollbar thumb appears at right edge during scroll, fades when stopped
  2. Open "Add Expense" sheet — EXPECTED: no scrollbar thumb visible inside the sheet
  3. Open Settings > tap Currency — EXPECTED: no scrollbar inside the currency sheet
  4. Repeat scrollbar check on Income and Stats screens
  </how-to-verify>
