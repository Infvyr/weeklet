Declare a single top-level async function:

  Future<List<S>> collectStates<S>(
    Bloc<dynamic, S> bloc,
    Future<void> Function() action, {
    int times = 100,
  }) async {
    final emitted = <S>[];
    final sub = bloc.stream.listen(emitted.add);
    await action();
    await pumpEventQueue(times: times);
    await sub.cancel();
    return emitted;
  }

Import: flutter_test (for pumpEventQueue), flutter_bloc (for Bloc). The function subscribes before calling action so no emits are missed, pumps the event queue to drain all nested bloc.add() calls (times: 100 is sufficient for all handlers in this codebase), then cancels the subscription.
