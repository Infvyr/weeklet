SettingsBloc is the most complex BLoC in the codebase: 7 constructor-injected use cases, one BiometricService dependency, side-effects through LocaleManager, and 4 sibling BLoC calls via GetIt in the ResetAllDataRequested handler.

LocaleManager is a pure Dart singleton (confirmed: lib/core/utils/locale_manager.dart reads no platform channels — it only sets intl.Intl.defaultLocale and a private _currentLocale field). LocaleManager._instance persists across tests; this is safe because it only affects locale formatting, not BLoC state.

IMPORTANT: The SettingsBloc._onLocaleChanged handler calls PlatformDispatcher.instance.locale (dart:ui) when event.locale is null — to get the device locale for fallback. The locale test for LocaleChanged(null) must call TestWidgetsFlutterBinding.ensureInitialized() before building the bloc to ensure the test binding is initialized.

BiometricService wraps local_auth. It must be stubbed — never invoke the real implementation in unit tests. The stub implements the two-method interface and exposes an authenticateResult: bool field to control test outcomes.
