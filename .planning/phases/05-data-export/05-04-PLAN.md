<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 1: Verify PDF export flow for expenses and income</name>
  <what-built>
    - PDF export icon (Icons.picture_as_pdf) added to app bar of Expenses screen and Income screen
    - Tapping icon generates a styled PDF and opens the OS native share sheet
    - Loading spinner replaces icon during generation
    - Error snackbar on failure; icon restored after error
    - Guard: selecting "All Months" then tapping export shows snackbar instead of generating
    - PDF structure: branded header (#1447E6), summary row, data table with alternating rows, totals row
    - Expense PDF: 4 columns (Date | Category | Description | Amount); category names resolved from IDs
    - Income PDF: 3 columns (Date | Description | Amount); amounts in green (#16A34A)
    - Currency symbol read from SettingsBloc state (active setting at export time)
    - File naming: weeklet_expenses_{month}_{year}.pdf / weeklet_income_{month}_{year}.pdf
  </what-built>
  <how-to-verify>
    Run the app on iOS simulator or Android emulator:
    `fvm flutter run`

    **Test 1 — Expense export (EXP-01):**
    1. Add at least 2 expenses in different categories for the current month if not already present
    2. On the Expenses screen, select the current month in the filter bar
    3. Tap the PDF icon (top-right of app bar)
    4. Observe: icon replaced by circular spinner during generation (< 5 seconds)
    5. Observe: OS native share sheet opens with a .pdf attachment
    6. Open the PDF in a viewer (Files app on iOS, or any PDF viewer on Android)
    7. Verify PDF contents:
       - Header: "Weeklet" title (white text, blue background #1447E6)
       - Subtitle: "Expense Report · {current month and year}" e.g. "Expense Report · April 2026"
       - Generated date line (e.g. "Generated: 12 April 2026")
       - Summary row: "Records: N" and "Total: {currency} {amount}"
       - Data table with columns: Date | Category | Description | Amount
       - Category column shows names (e.g. "Food"), NOT UUIDs
       - Totals row (blue background, white text) with correct summed amount
       - Amount column currency matches current Settings → Currency setting
    8. Verify: total in PDF matches sum of expense amounts visible in the list

    **Test 2 — Income export (EXP-02):**
    1. Navigate to Income screen
    2. Select the current month in the filter bar
    3. Tap the PDF icon
    4. Open the PDF in a viewer
    5. Verify PDF contents:
       - Header: "Weeklet" title, "Income Report · {month year}"
       - Data table with columns: Date | Description | Amount (3 columns — NO Category column)
       - Amount values in green color
       - Totals row correct
    6. Verify: total in PDF matches sum of income amounts visible in the screen

    **Test 3 — All Months guard:**
    1. On Expenses screen, use the filter bar to select "All Months" (null month)
    2. Tap the PDF icon
    3. Verify: snackbar appears saying "Please select a specific month to export."
    4. Verify: NO share sheet opens, NO PDF generated
    5. Repeat on Income screen

    **Test 4 — Loading state:**
    1. On a month with several records, tap export
    2. Observe: the icon is replaced by a white circular progress indicator during generation
    3. Observe: icon returns to picture_as_pdf after share sheet is dismissed

    **Test 5 — Error recovery (optional — skip if hard to reproduce):**
    If possible, trigger an error (e.g., temporarily set a bad temp path in use case)
    and verify: error snackbar with "Failed to generate PDF. Please try again." appears,
    icon returns to idle state.
  </how-to-verify>
  <resume-signal>
    Type "approved" if all tests pass.
    Or describe any issues found — Claude will fix and re-verify.
  </resume-signal>
